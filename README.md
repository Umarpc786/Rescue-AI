# 🚨 RescueAI — Multi-Agent Emergency Response Decision-Support System

**Product Requirements Document (PRD) v1.0 • Hackathon MVP • October 2026**

RescueAI is an orchestrated multi-agent AI prototype designed to convert unstructured emergency reports into structured, evidence-backed, and prioritized response plans. By coordinating specialized agents for triage, geospatial context, live weather, vector-based protocol retrieval, and safety reviews, RescueAI provides an observable decision-support system.

---

## ⚠️ Important Safety Boundary & Disclaimer

> **DECISION-SUPPORT ONLY:** RescueAI is designed strictly as an evidence-gathering decision-support prototype. It does **NOT** provide medical diagnosis, direct emergency dispatch, or direct control over emergency infrastructure. In a real emergency, always contact official local authorities immediately.
